┌─────────────────────────────────────────────────────────────────┐
│ PROBLEM / 问题说明                                              │
│                                                                 │
│ Windows 10 22H2 has a known LxssManager bug:                    │
│ After abnormal WSL shutdown, wslservice.exe gets stuck          │
│ in a zombie state and cannot be killed.                         │
│ This forces WSL VM to rebuild every 1-3 minutes.                │
│ Microsoft never backported the fix to Windows 10.               │
│                                                                 │
│ Windows 10 22H2 的 LxssManager 已知 bug：                       │
│ WSL 异常关闭后 wslservice.exe 卡死成僵尸，                       │
│ 导致 VM 每隔 1-3 分钟重建，服务反复断连。                        │
│ Microsoft 未向 Win10 推送修复。                                  │
└─────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────┐
│ DETECTION (Safe — No False Positives) / 检测机制（不会误杀）    │
│                                                                 │
│  Safeguard 1: Only "Stopped", NOT "Stop Pending"                │
│               只匹配 "Stopped"，不匹配 "Stop Pending"            │
│               (excludes normal shutdown / 排除正常关机)          │
│                                                                 │
│  Safeguard 2: Process age > 60 seconds                          │
│               进程存活 > 60 秒才杀                               │
│               (excludes transient states / 排除开关机瞬态)       │
│                                                                 │
│  Safeguard 3: Double-check after 3s delay before killing        │
│               等待 3 秒双重确认后才杀                            │
│               (eliminates false positives / 排除误判)            │
│                                                                 │
│  Steps / 步骤:                                                  │
│    1. wslservice.exe running >60s + LxssManager "Stopped"       │
│    2. Re-verified after 3 seconds / 3 秒后再次确认              │
└─────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────┐
│ KILL METHODS (Auto-fallback) / 杀进程方式（自动降级）            │
│                                                                 │
│  1. Backstab (kernel driver, Microsoft-signed / 内核驱动)        │
│  2. taskkill /F                                                 │
│  3. Stop-Process -Force                                         │
└─────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────┐
│ INSTALL (Admin) / 安装（需要管理员权限）                          │
│                                                                 │
│  ⚡ One-click / 一键安装：双击 一键安装.vbs                       │
│                                                                 │
│  Or command line / 命令行：                                      │
│    powershell -File kill-zombie.ps1 -Install                    │
│    — or —                                                       │
│    install.bat                                                  │
│                                                                 │
│  What happens / 安装后：                                         │
│  - Creates scheduled task "KillWSLZombie"                       │
│  - Triggers at boot + LxssManager start                         │
│  - Checks every 30s, kills zombie, stops until next trigger     │
│  - Downloads Backstab.exe if missing                            │
│  - Adds Defender exclusion                                      │
└─────────────────────────────────────────────────────────────────┘
